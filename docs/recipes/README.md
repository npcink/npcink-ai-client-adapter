# OpenClaw Recipe Guides

Consumer-facing playbooks for common OpenClaw workflows. Each recipe chains
read abilities, Core proposals, and explicit execution profiles that Adapter
already exposes; a recipe never registers runtime state, callbacks, or
workflow definitions in Adapter (see `docs/architecture/adapter-boundary.md`).
